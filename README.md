# Hangman Game Using Python

## Project Overview
This project is a simple, text-based Hangman game developed using Python as part of the CodeAlpha Python Programming Internship.

The player must guess a randomly selected hidden word one letter at a time. The player wins by guessing all the letters before running out of attempts.

## Features
- Random word selection
- Letter-by-letter guessing
- Displays hidden letters using underscores
- Checks correct and incorrect guesses
- Allows a maximum of six incorrect guesses
- Detects win and loss conditions
- Prevents repeated guesses
- Validates user input

## Technologies Used
- Python
- Visual Studio Code

## How to Run
1. Install Python.
2. Download the `hangman.py` file.
3. Open a terminal in the folder containing the file.
4. Run the following command:

   python hangman.py
